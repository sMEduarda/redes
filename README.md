# Quiz de Redes

Um quiz interativo em Python sobre conceitos de redes de computadores (focado em IPv4, máscaras de rede, etc.).  
Codigo adaptável para estudar ou treinar para provas e entrevistas.

## Funcionalidades

- Interface colorida (usando Colorama)
- Perguntas de múltipla escolha
- Feedback imediato (certo/errado)
- Contagem de pontuação final
- Fácil de modificar as perguntas

## Como Executar

### Pré-requisitos

- Python 3.8 ou superior instalado
- Biblioteca `colorama`

### Passo a passo

1. Clone o repositório ou baixe o projeto:

```bash
git clone https://github.com/sMEduarda/QUIZ-DE-REDES.git

2. Entre na pasta do projeto:

QUIZ-DE-REDES

3. Instale a dependência:

py -m pip install colorama

4. Execute o quiz:

py quiz.py

#### Tecnologias Utilizadas

Python 3
Colorama (para cores no terminal)
